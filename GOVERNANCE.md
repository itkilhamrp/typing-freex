# Project Governance

Typing FreeX operates under a maintainer-led free and open-source governance model.

## Roles

- **Core Maintainers**: Responsible for overall architecture, release signing, security reviews, and repository administration.
- **Module Owners**: Review and guide changes to specific domains (e.g. typing engine, database layer, hand guide).
- **Contributors**: Propose enhancements, fix bugs, submit content packs, and participate in discussions.

## Decision Making

Architectural decisions follow the ADR process documented in `docs/adr/`. Non-trivial changes must be preceded by an RFC or PRD amendment before implementation.
