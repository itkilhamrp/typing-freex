# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Typing FreeX project takes the security of its offline desktop engine seriously. Because Typing FreeX is designed with strict privacy and zero remote network access, any bypass of these isolation boundaries is considered a high-priority security issue.

If you discover a security vulnerability, please report it via private security advisory on GitHub or by contacting the security maintainers directly.

### Disclosure Timeline
- **Initial acknowledgment**: within 48 hours.
- **Triage and reproduction**: within 7 days.
- **Fix and disclosure**: 90-day responsible disclosure window.
